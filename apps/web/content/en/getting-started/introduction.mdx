Nebula is a **web and React Native** UI library with the same API per component. Contracts live in the
tokens package and each platform implements only the visual layer.

## The idea behind it

Two products that look nothing alike should still be able to share a catalogue. Nebula gets there
**with themes alone**: one object describing colour, density, radii, motion and effects. No forks, no
renamed copies of a component.

## Status

The web catalogue is complete — 158 components across seven subpaths — and the API is being
normalised. Until v1 it may change without notice.
