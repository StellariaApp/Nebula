# Qué es Nebula

Nebula es una librería de interfaz **web y React Native** con la misma API por componente. Los
contratos viven en los tokens y cada plataforma implementa solo la capa visual.

## La idea de fondo

Dos productos que no se parecen en nada deberían poder compartir catálogo. En Nebula eso se consigue
**solo con temas**: un objeto que describe color, densidad, radios, motion y efectos. No hay forks, no
hay copias del componente con otro nombre.

## Estado

El catálogo web está completo y la API está en normalización. Hasta la v1 puede cambiar sin aviso.
